Robom Games v9 — Осеннее обновление 🍂

Что нового

В этой версии Robom Games получил осеннее оформление и несколько атмосферных изменений.

🍁 Осеннее меню
- Обновлён внешний вид главного меню.
- Добавлена осенняя атмосфера.
- Появились падающие листья.
- Добавлены новые осенние визуальные элементы.

🍂 Новая мини-игра — «Листопад»
- Собирайте падающие листья.
- За успешные нажатия увеличивается счёт.
- За определённое количество собранных листьев можно получать Токены.

 🍁 Осенний секрет
В главном меню спрятан небольшой секрет. Попробуйте найти его самостоятельно.

 🎮 Осталось без изменений
- Вход и регистрация по никнейму.
- Сохранение аккаунта.
- Волейбол.
- Набивание мяча.
- Токены и Робомы.
- Панель разработчика.
- Система обмена валюты.

 Установка

1. Распакуйте архив.
2. Загрузите файлы проекта в репозиторий GitHub.
3. Убедитесь, что `index.html` находится в корне сайта.
4. Откройте GitHub Pages.
