ROBOM GAMES v8 — REMAKE АВТОРИЗАЦИИ

Изменения:
- Вход теперь выполняется по НИКНЕЙМУ и паролю, без почты.
- Регистрация создаёт аккаунт с никнеймом и паролем.
- Сохранённый аккаунт не удаляется при выходе.
- Добавлена поддержка аккаунтов старых версий с сохранённым ником.
- Добавлена кнопка «Показать пароль» на экране входа и регистрации.
- Сохранены игры, таймеры, Токены, Робомы, обмен и панель разработчика.
- Сохранено красивое меню Robom Games.

Важно:
Аккаунт хранится в localStorage браузера. Если очистить данные сайта или сменить браузер/устройство, аккаунт локально не перенесётся.
