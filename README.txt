АПРЕЛЬСКОЕ ОБНОВЛЕНИЕ

Что изменилось:
- «Для разработчиков» теперь специально предупреждает: «это для разрабов обычным смертным не кликать».
- Пароль разработчика в этой панели отключён — она открывается сразу после предупреждения.
- При попытке выдать Токены или Робомы срабатывает первоапрельский розыгрыш.
- Появляется сообщение: «ахахахах лох твою валюту забрали».
- Кнопка «Я больше так не буду» открывает инструкцию обновить страницу.
- Токены и Робомы временно становятся 0 только как эффект розыгрыша.
- После обновления страницы сохранённая валюта автоматически возвращается.
- Реальная потеря валюты невозможна: перед розыгрышем баланс сохраняется в отдельной резервной записи.

Важно:
Это шуточное первоапрельское обновление. Эффект рассчитан на локальное сохранение аккаунта в браузере.

Основные возможности Robom Games сохраняются: игры, таймеры, Токены, Робомы, обмен валюты, авторизация по никнейму и красивое меню.
